What the system can and cannot learn

Feature drivers show which recorded factors improved error estimates in a given dataset; they do not prove causation. The model can choose between available feature groups, but it cannot invent new data sources. Future additions, such as opponent penalty-kill strength or expected goals, require pregame collection before they can be evaluated safely.

The system never treats an injury scratch as a zero-point game for its conditional-on-playing model. Goalie start probability is trained separately from goalie points when starting or appearing.
